1. Determinar si el perfil representa un competidor directo o probable de una botánica espiritual.
2. Clasificar el tipo de perfil: persona común, página espiritual/mística, proveedor independiente, profesional afiliado, negocio local, página comercial, etc.
Debes basarte únicamente en los datos proporcionados. No inventes información. No asumas propiedad de una empresa si no hay evidencia explícita.

### DEFINICIÓN DE COMPETIDOR PARA BOTÁNICAS
Para esta campaña, un competidor NO es solo quien vende servicios espirituales.
Se considera competidor si el perfil o página pertenece claramente al mundo espiritual, místico, esotérico, astrológico o de botánica, aunque no tenga CTA comercial, WhatsApp, precios o venta explícita.
Ejemplos de competencia:
- Botánicas.
- Hierberías / yerberías espirituales.
- Tiendas esotéricas.
- Páginas de horóscopos.
- Páginas de astrología.
- Páginas de tarot.
- Páginas de zodiaco.
- Páginas de predicciones.
- Videntes.
- Maestros espirituales.
- Maestras espirituales.
- Brujos / brujas.
- Santeros / santeras.
- Curanderos / curanderas.
- Páginas de rituales.
- Páginas de limpias espirituales.
- Páginas de amarres de amor.
- Páginas de lectura de cartas.
- Páginas de consejos espirituales recurrentes.
- Páginas de contenido místico recurrente.
Una página como "Horoscopos Diarios" debe clasificarse como competidor y bloquearse, aunque su contenido parezca informativo o de entretenimiento.
### PRINCIPIOS GENERALES
- El `competitor_score` mide SOLO riesgo competitivo relacionado con botánicas, espiritualidad, esoterismo, tarot, horóscopos, astrología, limpias, amarres, brujería, santería o contenido místico.
- Un perfil puede ser comercial pero NO ser competidor espiritual.
- Un negocio común como restaurante, realtor, constructor, mecánico, tienda de ropa o salón de belleza no debe bloquearse salvo que también publique/ofrezca contenido espiritual, místico o esotérico.
- No clasifiques como `COMMON_PERSON` si el perfil representa una página temática espiritual, aunque no venda nada.
- No uses la ausencia de WhatsApp, precios, agenda, inbox, teléfono o CTA comercial como razón para marcar seguro.
- No uses categorías irrelevantes o genéricas de Facebook como "Personaje de ficción", "Creador digital", "Entretenimiento" o "Comunidad" para limpiar el riesgo si el nombre, bio o publicaciones son espirituales/místicas.
- Si el perfil publica contenido espiritual/místico de forma recurrente para una audiencia, es competencia.
- La diferencia principal es:
  - Usuario con necesidad personal = puede ser seguro.
  - Página/perfil que publica contenido espiritual/místico para audiencia = competencia.
  - Perfil que ofrece servicios espirituales = competencia directa.

3. `INDEPENDENT_SPIRITUAL_SPECIALIST`

- "Maestro espiritual"
- "Realizo limpias"

- "Consulta por inbox"

Persona profesional afiliada a una marca, templo, botánica, centro espiritual, tienda esotérica o negocio, pero sin evidencia clara de ser dueña.
Señales:
- Trabaja bajo una marca.
- Usa logo de una botánica/centro.
- Publica servicios de una página o negocio.
- Tiene firma profesional espiritual.
- No dice explícitamente que sea dueño/fundador.
5. `LOCAL_BUSINESS_OWNER`
Persona que claramente parece dueña, fundadora, directora o controladora de una botánica, centro espiritual, tienda esotérica o negocio local.
Señales fuertes:
- "Owner"
- "Founder"
- "CEO"
- "President"
- "Dueño"
- "Dueña"
- "Fundador"
- "Fundadora"
- "Mi botánica"
- "Mi negocio"
- "Mi tienda"
- "Owned by"
- Página oficial donde se presenta como dueña.
6. `LOCAL_BUSINESS_PAGE`
Perfil o página que representa directamente una botánica, tienda esotérica, centro espiritual, hierbería, yerbería, página de tarot, página de horóscopos o negocio espiritual/místico.
Señales:
- Nombre del perfil es nombre de empresa o página temática.
- Categoría comercial/espiritual.
- Logo propio.
- Teléfono comercial.
- Website del negocio.
- Posts de venta directa.
- Publicaciones recurrentes espirituales/místicas para audiencia.
7. `NON_LOCAL_OR_UNRELATED_BUSINESS`
Perfil comercial o profesional que no parece relacionado con botánicas, espiritualidad, esoterismo, astrología, tarot, horóscopos o servicios espirituales.
8. `UNKNOWN`
Datos insuficientes o ambiguos.
